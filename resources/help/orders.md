## What this page is for

Orders track what customers asked for, from the first draft to delivery. Confirming an order reserves its stock and dispatching it deducts the stock, oldest batch first.

## Tasks

### Create an order

1. Open Orders and select New order.
2. Choose the customer, or add one with Add and select.
3. Add each product and quantity, and the requested delivery date.
4. Select Save draft.

### Confirm an order

1. Open the draft order.
2. Select Confirm. If any product is short, the order stays a draft and the shortfall is shown.

### Dispatch an order

1. Open the confirmed order.
2. Select Dispatch and confirm. Stock is deducted, oldest batch first, and the order is marked dispatched.
3. Select Mark delivered once the customer has received it.

### Add a customer

1. Open Orders and select the Customers tab.
2. Select Add customer, fill in their details and payment terms, then select Save customer.

## What each access level lets you do

- **View:** see orders and customers.
- **Full:** also create, edit, confirm, dispatch, deliver and cancel orders, and manage customers.

## Common problems

- **Confirm says stock is short.** Other confirmed orders have reserved that stock. Wait for stock-in, or send the production team a request.
- **You can't edit an order.** Only drafts can be edited. Cancel a confirmed order and create a new one instead.
- **Dispatch is blocked.** Stock on hand fell below what the order needs since it was confirmed.

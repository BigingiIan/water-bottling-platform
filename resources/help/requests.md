## What this page is for

Requests are how teams ask each other to act. The Inbox holds requests addressed to your team, Sent holds the ones you sent, and administrators also see All requests.

## Tasks

### Pick up a request for your team

1. Open Requests. The Inbox shows your team's open requests, urgent and oldest first.
2. Open a request and select Assign to me so others know you have it.
3. Select Acknowledge or Start work so the sender sees progress.

### Finish or decline a request

1. Open the request.
2. Select Mark done and add a short note on what was done.
3. Or select Decline and say why, so the sender knows what to do next.

### Reply in the thread

1. Open the request.
2. Write in the comment box and select Post comment. The other side is notified.

### Find overdue requests

1. Open Requests and tick Overdue only.
2. Use the status, type and priority filters to narrow the list.

## What each access level lets you do

- **View:** read requests you sent and requests addressed to your team.
- **Full:** also send requests, reply, and change the status of requests addressed to your team.

## Common problems

- **You can't change a request's status.** Only the team it is addressed to, or an administrator, can.
- **A request disappeared from the Inbox.** It is done, declined or cancelled. Set the status filter to All statuses.
- **You were notified about an overdue request.** Its due date has passed and it is still open. Finish it, or reply with a new date.

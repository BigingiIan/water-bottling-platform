## What this page is for

Production covers the daily schedule, the runs on each production line and the history of what was made. A run is planned on the schedule, logged while it happens and completed when the line stops.

## Tasks

### Schedule a production run

1. Open Production › Schedule.
2. Select Create Schedule.
3. Choose the product, line, date, time and target units.
4. Select Create Run.

### Log production

1. Open Production › Production Runs and pick the day.
2. Select an active run to open its details.
3. Select Log Production, enter the units produced and the quality result.
4. Select Save Entry. The run's progress updates straight away.

### Complete a run

1. Open the run on Production Runs.
2. Select Complete run.
3. Enter the raw water used and the metered bottled volume, then select Complete.
4. The batch is created and any loss beyond the normal process loss is flagged for review.

### Review past runs

1. Open Production › History.
2. Filter by date, line or product to compare output against targets.

## What each access level lets you do

- **View:** see the schedule, open runs and history.
- **Full:** also schedule runs, log production and complete runs.

## Common problems

- **Log Production is greyed out.** Your role has View access only, or the run is not active.
- **A run is missing.** Check the selected day. Runs belong to the day they were scheduled.
- **Completing a run flags a loss.** The bottled volume fell short of what the line normally loses. An inventory user reviews it under Leakage Reports.

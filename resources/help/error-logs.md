## What this page is for

Error logs record the access-denied and server errors people saw, each with a reference code shown on the error page. Use them to find what went wrong when a colleague reports a problem.

## Tasks

### Find an error a colleague reported

1. Ask for the reference code shown at the bottom of their error page.
2. Open Error Logs and search for the reference.
3. Open the entry to see when it happened, who saw it and on which page.

### See repeated errors

1. Switch to Grouped to see errors with the same cause together.
2. Open a group to see every occurrence.

### Mark an error resolved

1. Open the error.
2. Add a note on what was fixed and select Mark resolved.

## What each access level lets you do

- **View:** see recorded errors and their references.
- **Full:** also mark errors resolved with a note.

## Common problems

- **You can't find the reference.** Old errors are removed after the retention period set in Settings.
- **The page shows no technical detail.** Exception details are never shown on error pages, so users can't see private information.
